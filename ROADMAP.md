# Roadmap

## Bootstrap

- Define Phase's problem statement, users, and non-goals.
- Document the initial architecture and threat model.
- Agree on the first public API through a design proposal.

## First usable release

- Implement the smallest end-to-end capability.
- Add examples, API documentation, fuzz targets, and integration tests.
- Establish measurable coverage and performance baselines.

## Stable release

- Complete compatibility and security reviews.
- Publish an explicit support policy and release runbook.
- Add provenance, SBOM, and signed artifact automation if binaries are shipped.
