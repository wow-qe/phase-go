# Governance

Phase Go uses a maintainer-led, consensus-seeking model.

- Contributors propose changes through issues and pull requests.
- Maintainers review changes, manage releases, and protect project security.
- Routine decisions are made through review consensus.
- Material changes to public APIs, compatibility, security boundaries, or
  governance require a documented proposal and approval from two maintainers
  when two eligible maintainers are available.
- If consensus cannot be reached, the lead maintainer records the decision and
  rationale publicly. Decisions may be revisited when new evidence appears.

Maintainer membership is based on sustained, constructive contribution and can
be removed for inactivity, security risk, or Code of Conduct violations after a
documented review.
