# Security Policy

## Supported versions

Before the first stable release, only the latest tagged version and the `main`
branch receive security fixes. After `v1.0.0`, supported release lines and
end-of-life dates will be listed here.

## Reporting a vulnerability

Do not open a public issue. Use GitHub private vulnerability reporting at:

https://github.com/wow-qe/phase-go/security/advisories/new

Include a description, reproduction steps, affected versions, likely impact,
and any suggested remediation. Maintainers aim to acknowledge reports within
48 hours, provide an initial assessment within five business days, and
coordinate disclosure after a fix is available.

Do not include secrets or sensitive production data in a report. Good-faith
research that avoids privacy violations, service disruption, and data loss is
welcome.
